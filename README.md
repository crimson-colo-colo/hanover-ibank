# CS 3733 D26 - Team C Hanover Insurance iBank Application

This is the project repository for CS 3733 Team C. This repository contains both the React
frontend and Node.js / bun backend.

See [DEVELOPMENT.md](DEVELOPMENT.md) for instructions on how to set up the
development environment and run the project.

# Special Features
* Email notifications
* Thumbnail content preview
* Pop-out content preview 
* AI spotlight search
* OCR of documents
* Light/dark theme toggle
* Auth0 for authentication and authorization
* Discussion board and threads on content
* Pagination for content table and user table
* Advanced content tag filtering
* Heatmap and treemap for in-depth user and content analysis
