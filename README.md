# CS 3733 D26 - Team C

Project repository for CS 3733 Team C. This repository contains both the React 
frontend and Node.js backend.

Run the command below to open the database.
```shell
docker compose up -d
```

# When starting to use the project:
1. install packages
2. start the databases
3. start the dev server

```shell
bun install;
bun run db:start;
bun run dev;
```
